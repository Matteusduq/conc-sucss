# Portfolio screenshots and demo checklist

Add screenshots to `docs/screenshots/` after capturing them from a local or deployed instance with **synthetic data only**.

Recommended files:

1. `01-daily-dashboard.png` — daily study cockpit.
2. `02-study-plan.png` — adaptive study plan.
3. `03-performance-analytics.png` — analytics charts.
4. `04-spaced-repetition.png` — flashcard reviews.
5. `05-document-reader.png` — PDF reader and annotations.

Suggested walkthrough (60–90 seconds): daily dashboard → study plan → analytics → spaced repetition → PDF reader → quick architecture summary.

Before publishing, remove personal names, private documents, email addresses, access tokens, and real student data. Do not add a demo URL until a working public demo exists.

After screenshots are uploaded, update the root README with image links like:

```markdown
![Daily dashboard](docs/screenshots/01-daily-dashboard.png)
```
